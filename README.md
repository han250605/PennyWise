# PennyWise

PennyWise is a Python command-line personal finance tracker. It helps users record and review expenses, understand monthly spending, track savings goals, and receive supportive recommendations from a rule-based financial coach.

Keeping expenses and goals in one small local tool makes it easier to notice spending patterns and plan toward a savings target. PennyWise is intended for manual tracking and learning; it does not connect to banks or provide professional financial advice.

## Features

- Add, view, edit, and delete expenses. Each expense has a random six-digit reference ID for convenient editing and deletion; the internal UUID remains stored with the record.
- Generate monthly spending reports with totals, category percentages, rankings, and a 20-character Unicode bar chart.
- Create and view multiple savings goals, choose them by their numbered creation order, and record contributions.
- Set a planned monthly contribution, see estimated months to completion, and edit a goal's name, target, or contribution plan.
- Get monthly recommendations from the AI Financial Coach and see estimated next-month goal progress when the goal has a savings plan.
- Save expenses, goals, and contributions locally in JSON.
- Navigate through interactive terminal menus and submenus.

The coach is a **rule-based program**, not a generative AI model. It applies predefined spending guidelines and arithmetic to the user's saved data. Its thresholds are suggestions, not universal financial standards. Projections are estimates and do not move money or guarantee a result.

## Requirements

- Python 3.12
- `pip`
- A terminal (macOS, Windows, or Linux)

## Installation

1. Clone the published project. Replace the placeholder with the URL of the public repository after it has been created:

   ```text
   git clone https://github.com/<YOUR-USERNAME>/PennyWise.git
   cd PennyWise
   ```

2. Create a virtual environment using Python 3.12:

   ```text
   python3.12 -m venv .venv
   ```

   On Windows, use the Python launcher if `python3.12` is not available:

   ```text
   py -3.12 -m venv .venv
   ```

3. Activate the environment.

   macOS or Linux:

   ```text
   source .venv/bin/activate
   ```

   Windows PowerShell:

   ```text
   .venv\Scripts\Activate.ps1
   ```

   Windows Command Prompt:

   ```text
   .venv\Scripts\activate.bat
   ```

4. Install the project dependencies:

   ```text
   python -m pip install -r requirements.txt
   ```

   `requirements.txt` contains pytest for testing. The application itself uses Python's standard library.

## Run PennyWise

From the project directory, with the virtual environment active:

```text
python main.py
```

The main menu is:

```text
===== PENNYWISE =====
1. Manage Expenses
2. Monthly Spending Overview
3. Manage Savings Goals
4. AI Financial Coach
5. Exit
Select an option:
```

Choose **Manage Expenses** to add, view, edit, or delete an expense. Expense prompts accept one of the displayed category numbers and a date in `YYYY-MM-DD` format; pressing Enter at a new expense's date prompt uses today's date. **Manage Savings Goals** lets you create a goal, view goals, add a contribution, or edit a goal. Savings goals are selected by their displayed number. The monthly report and coach are available directly from the main menu. View screens pause so their output can be read before returning to their submenu.

Then choose **AI Financial Coach** from the main menu and enter a month/year that contains fictional spending. If fictional entertainment spending was $600 of a $2,000 monthly total and the goal data above is saved, the coach can show output such as:

```text
===== AI FINANCIAL COACH =====

Month: November 2026
Total Monthly Spending: $2,000.00

AI Insight:
Your entertainment spending accounts for 30.0% of your monthly expenses.
This is above the suggested guideline of 25%. Consider reducing entertainment spending.

Next Month (With AI Advice): 44.13%
```

The displayed reduction and projections are calculated from the saved expenses and goal plan. They are estimates only; PennyWise does not transfer or reserve money.

## Tests

Activate the virtual environment, then run:

```text
python -m pytest -v
```

Tests use pytest temporary directories or in-memory values rather than the real finance data file. The latest local review run completed with **109 passing tests**. GitHub Actions is configured to run the suite on pushes to `main` and pull requests targeting `main`; remote workflow results must be checked on GitHub after publication.

## Known Limitations

- Data is stored as a local JSON file, not encrypted or synchronized. Protect access to the computer and keep backups in a secure place.
- Expenses and savings contributions must be entered manually; there is no bank integration.
- The coach uses predefined rules and percentages. It is not generative AI, a financial advisor, or a complete assessment of someone's financial health.
- Spending recommendations and goal projections are estimates. Results depend on accurate entries and, for projections, on successfully following the stated savings plan and redirecting any reduced spending.
- The application has no multi-user accounts, cloud backup, or advanced recovery for a JSON file whose individual records have an invalid structure.
- The clone URL in the installation example is a placeholder until the public course repository is published.
